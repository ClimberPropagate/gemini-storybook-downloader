## 🚨 Symptoms of a Broken Storybook Archive

Before you export another story, check whether your archive suffers from any of these classic problems. Each one points to a specific fix this guide teaches.

| **Symptom** | **What It Really Means** | **Fix This Guide Teaches** |
|-------------|---------------------------|------------------------------|
| 😵 Text and image mismatched | Wrong page order | Page index map |
| 🐌 Export takes hours | Re-rendering images | Cache assets |
| 🧊 PDF text blurry | Rasterized text | Text layer |
| 🔥 EPUB broken | No manifest | OPF build |
| 📉 Images lost | Hotlink expiry | Local copy |
| 🔇 No metadata | Missing title | Front matter |

> **💡 Tip:** If text and images drift out of order, your page index map is off by one — verify against the source story.
